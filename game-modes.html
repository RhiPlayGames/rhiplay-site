First Guess Game Modes

First Guess includes several different challenges. They share a focus on clues, discovery and making decisions, but each mode has its own rules and scoring.

Classic First Guess

Answer knowledge questions using up to ten clues. You start with three lives. The earlier you answer correctly, the higher the XP award, with an extra bonus for a correct first guess.

Daily Flash 5

Five daily challenges provide a shorter session and offer double XP. Daily Flash includes different puzzle styles, so read the instructions presented before each challenge.

First Word

Identify a hidden word from five clues. Letter hints appear as you progress, but the opening letter is not revealed until the final clue. You have three guesses, and early correct answers score more XP.

First Pick

Choose the correct answer from the choices displayed. Unlike free-text Classic guesses, this mode asks you to make a selection.

First Match

Connect matching items into pairs. Pay close attention to both sides of the screen, then complete all required matches.

First Order

Arrange the presented items in the correct sequence. The required order depends on the challenge.

First Date

Use the question clues and dates to identify the correct answer. The game explains its particular controls when you begin.

Case Files

Travel through themed adventures and sequential missions, unlocking subsequent challenges as you progress. Adventures include subjects such as animals, countries, history and literature.

Which should I try first?

If you enjoy general knowledge and deciding when to take a risk, begin with Classic. If you prefer short sessions, try Daily Flash 5. If you like puzzles, explore First Word, First Match or First Order.
